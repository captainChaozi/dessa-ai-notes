# Comparison pages

The independent [Dessa AI guide](https://dessaai.org/) keeps three comparison pages. Each separates what you can actually use today from what is only described in research material.

| Page | Core question |
|---|---|
| [Dessa vs ChatGPT Voice](https://dessaai.org/dessa-vs-chatgpt-voice) | A research model with recordings vs a voice mode inside a shipping product |
| [Dessa vs Sesame](https://dessaai.org/dessa-vs-sesame) | Two expressive-voice efforts: which one has an app or preview you can try? |
| [Dessa AI alternatives](https://dessaai.org/alternatives) | What to use if you need a voice AI now |

Ground rules used on all three:

- Compare like with like: product vs product, model vs model.
- Curated recordings are not a controlled listening test.
- Access, API, pricing and data handling are stated only when a primary source confirms them (checked 25 October 2026).
