# Dessa AI: four kinds of "release" and what each would need

Block introduced the Dessa speech-to-speech research model on 2026-10-23 (16:38 UTC). People often ask "is it released yet?" as if that were one question. It is at least four. This page is a checklist for reading future announcements. It summarises the [download guide](https://dessaai.org/download) and [API guide](https://dessaai.org/api) on [dessaai.org](https://dessaai.org/), an independent information site.

| Release type | What it would let you do | What still needs checking | Status at 2026-10-25 check |
|---|---|---|---|
| Interactive public service | Talk to the model and get new responses | Who can sign up, region, cost, data terms | Not verified; only recordings and a researcher invitation |
| Desktop application | Use a packaged interface locally | Supported OS, account requirement, network dependence | Not verified |
| Model weights | Load the model in a compatible runtime | License, architecture, precision, dependencies, memory | Not verified |
| Source code | Inspect or run the implementation | Whether weights and assets are also released | Not verified |
| Hosted API | Call a remote service from your app | Documentation, keys, pricing, rate limits, data use | Not verified |

## Rules of thumb

- An announcement date is not a public-access date.
- A hardware statement (Block says MacBook Pro M4 Max or better) is not a download.
- Source-code terms and weight terms can differ; running privately, modifying, redistributing and selling a hosted service are separate permissions.
- A failed source check is not evidence of a shutdown.
- Research access for AI safety researchers is decided by Block. Applying is not the same as being granted access.
